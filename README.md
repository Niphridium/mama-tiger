# Mama Tiger

Готовая сборка сайта для GitHub Pages: https://niphridium.github.io/mama-tiger/

Приложение для родителей детей 4–18 лет: практика дня по возрасту (чтение, счёт с проверкой ответа, головоломка, английский, дело для самостоятельности, письмо у старших), цели и пересмотр по каждому ребёнку, распорядок и нормы сна, движения и экранов по возрасту, детский режим. Без привязки к стране и школьной программе. Данные хранятся только в браузере. Материалы подготовлены с помощью ИИ, это не медицинский совет.
