# Мама-тигр 7–9

Готовая сборка сайта для GitHub Pages: https://niphridium.github.io/mama-tiger/

План на 12 недель для родителей детей 7–9 лет (1–3 класс) в Казахстане: распорядок дня, замеры раз в 4 недели, чек-лист и признаки перегрузки, секции Алматы и олимпиады. Данные хранятся только в браузере. Материалы подготовлены с помощью ИИ, это не медицинский совет.
